# minishell - 42 Paris

As beautiful as a shell. This project is about creating a simple shell. Yes, your own little bash. You will learn a lot about processes, file descriptors, signals, and parsing.

## 📝 About The Project

`minishell` is one of the biggest milestones in the 42 core curriculum. The objective is to write a custom shell program from scratch that mimics the behavior of `bash`. It must present a prompt, read user input, parse the command line, and execute commands while handling environment variables, redirections, pipes, and signals.

## 🧠 Architecture

This implementation is carefully structured and divided into distinct logical components to keep the immense codebase clean and manageable:

*   **Lexer (`./srcs/lexer/`):** Reads the raw string input and breaks it down into meaningful "tokens" (words, quotes, pipes, redirection operators). It handles the complex logic of keeping quotes intact (`'` and `"`).
*   **Parser (`./srcs/parser/`):** Takes the tokens generated by the lexer and organizes them into a command structure or Abstract Syntax Tree (AST). It checks for syntax errors before any execution begins.
*   **Pipe & Redirect (`./srcs/pipe_redirect/`):** The execution engine. It handles:
    *   Connecting commands via pipes (`|`).
    *   File redirections (`>`, `<`, `>>`).
    *   The complex `here_doc` (`<<`) implementation.
    *   Environment variable expansion (e.g., translating `$USER` into the actual username).
*   **Built-ins (`./srcs/built_in/`):** Custom implementations of essential shell commands that must run in the parent process or without calling external binaries: `echo`, `cd`, `pwd`, `export`, `unset`, `env`, and `exit`.

### Prerequisites

This project relies on the `readline` library for the command prompt and history. If you are on macOS, you must install it via Homebrew:

brew install readline
You will also need:
・GCC or Clang compiler
・Make

Compilation
Run the following command at the root of the repository to build the custom libft and the minishell executable:
Bash
make

💻 Usage
To start your shell, simply run the compiled executable:
Bash
./minishell

Once inside the prompt, you can use it just like a regular bash shell!
Supported Features:
・Execute standard system commands (e.g., ls -l, cat file.txt, grep "hello").
・Use pipelines to chain commands: ls -la | grep ".c" | wc -l.
・Redirect input and output: echo "Hello" > file.txt, cat < file.txt.
・Use Here-Documents: cat << EOF.
・Expand environment variables: echo $HOME, echo $?.
・Handle signals safely (Ctrl-C provides a new prompt, Ctrl-D exits, Ctrl-\ does nothing).
・Execute all mandatory built-in commands.
